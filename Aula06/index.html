1. Hiperlinks (<a>): Externos, Internos, Âncoras e mailto:

A tag <a> cria links clicáveis usando o atributo href:

  • Link externo: Aponta para outro site (usa target="_blank" e rel="noopener" para abrir em nova aba com segurança).
  • Link interno: Abre outra página do nosso próprio site (ex.: exemplos/pagina-destino.html).
  • Link para âncora (#id): Pula para um elemento na mesma página que tenha aquele id.
  • E-mail (mailto:): Abre o programa de e-mail.

Código de exemplo:

<!-- Link externo em nova aba -->
<a href="https://developer.mozilla.org/pt-BR/docs/Web/HTML" target="_blank" rel="noopener">
    Documentação MDN (Nova Aba)
</a>

<!-- Link interno para outra página do projeto -->
<a href="exemplos/pagina-destino.html">Abrir Página Destino</a>

<!-- Link para âncora (#topo) e link de e-mail (mailto:) -->
<a href="#topo">Ir para o Topo</a>
<a href="mailto:contato@escola.edu.br">Enviar E-mail</a>

Resultado renderizado no navegador:

Documentação MDN (Nova Aba) | Abrir Página Destino | Ir para o Topo | Enviar E-mail

⚠️ Erros comuns neste tópico:

  • Esquecer o https:// em links para sites externos.
  • Esquecer o símbolo # no link da âncora (ex.: escrever href="topo" em vez de href="#topo").

2. Imagens (<img>) e Acessibilidade (Atributo alt)

A tag <img> é uma tag vazia (não tem fechamento) e usa:

  • src: Caminho da imagem (prefira o caminho relativo da pasta do projeto, como img/codigo-html.svg).
  • alt: Texto alternativo de acessibilidade (lido por leitores de tela para pessoas com deficiência visual e exibido se a imagem falhar).
  • width e height: Largura e altura em pixels.
  • Imagem dentro de link: Coloque o <img> dentro da tag <a>...</a>.

Código de exemplo:

<!-- Imagem simples com alt, width e height -->
<img src="img/codigo-html.svg" alt="Janela de código HTML5" width="300" height="165">

<!-- Imagem clicável dentro de um link -->
<a href="exemplos/pagina-destino.html">
    <img src="img/banner-curso.svg" alt="Banner Técnico em Informática" width="280" height="157">
</a>

  • Deixar a imagem sem o atributo alt (prejudica a acessibilidade).
  • Errar o caminho da pasta no src (ex.: esquecer ../ quando está dentro de uma subpasta).

3. Introdução ao CSS Inline (Atributo style)

Usamos o atributo style="propriedade: valor;" para aplicar estilos visuais básicos:

  • color: Cor da letra (ex.: color: #1B2A4A;)
  • background-color: Cor de fundo (ex.: background-color: #FFF3CD;)
  • font-size: Tamanho da fonte (ex.: font-size: 22px;)
  • font-family: Tipo de fonte (ex.: font-family: Cambria, serif;)
  • text-align: Alinhamento do texto (left, center, right)
  • width: Largura da caixa (ex.: width: 500px;)
  • border: Borda (ex.: border: 2px solid #F2A541;)

Código de exemplo:

<p style="color: #1B2A4A; background-color: #FFF3CD; font-size: 20px; font-family: Cambria, serif; text-align: center; width: 500px; border: 2px solid #F2A541;">
    Parágrafo estilizado com CSS Inline!
</p>

Resultado renderizado no navegador:

Parágrafo estilizado com CSS Inline!

⚠️ Erros comuns neste tópico:

  • Esquecer o ponto e vírgula (;) entre uma propriedade e outra no style.
  • Usar sinal de igual (=) em vez de dois-pontos (:) dentro do style.

Por que o CSS inline não é a melhor prática em sites grandes? Porque repetir style="..." em todas as tags dá muito trabalho para manter. Nas próximas aulas usaremos o CSS Interno (tag <style> no <head>, como fizemos no topo desta página) e o CSS Externo (arquivo .css separado)!
